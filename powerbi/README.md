# Power BI Dashboards

This folder contains Power BI reports and supporting
documentation for the FinCorp Payment Fraud Monitoring
& Risk Analytics System.

## Planned Dashboard Pages

1. Executive Fraud Overview
   - Transaction volume and value
   - Fraud count, rate and amount
   - Monthly trends and risk levels

2. Fraud Patterns & Risk Analysis
   - Fraud by channel and payment method
   - Time and location patterns
   - Risk signals and customer behaviour

3. Detection Performance & Validation
   - TP, FP, FN and TN
   - Precision, recall and F1 score
   - Scenario detection rates
   - Missed fraud and false-positive analysis

## Deliverables
- Power BI report (.pbix)
- Dashboard screenshots
- DAX measures and KPI definitions
- Business insights and recommendations

All metrics will use validated project data.
