# Testing and Quality Assurance

This folder contains automated tests for the
FinCorp Payment Fraud Monitoring & Risk Analytics System.

## Planned Tests

1. Database schema and referential integrity checks
2. Missing values, duplicates and invalid data checks
3. Customer behaviour and transaction consistency checks
4. Synthetic fraud distribution checks
5. Historical feature and data leakage tests
6. Fraud rule and risk score calculation tests
7. Validation metric consistency checks
8. Reproducibility checks using fixed random seeds

## Objective

Ensure that generated datasets, fraud detection rules
and analytical outputs are reliable, reproducible and
properly validated.

All tests will be implemented and documented as
the project progresses.
