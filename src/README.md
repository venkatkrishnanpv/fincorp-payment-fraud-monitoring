# Python Source Code

This folder contains the Python scripts for the
FinCorp Payment Fraud Monitoring & Risk Analytics System.

## Data Generation
- Customer profiles
- Banks and bank accounts
- Debit and credit cards
- Customer devices
- Merchants
- Beneficiaries
- Payment transactions

## Fraud Analytics
- Customer behaviour simulation
- Fraud scenario injection
- Data quality validation
- Exploratory data analysis
- Historical feature engineering
- Rule-based fraud detection
- Risk scoring and classification
- Fraud detection performance evaluation

## Engineering Standards
- Reproducible random seeds and configuration
- Referential integrity across related tables
- Separation of fraud ground truth from detection features
- Prevention of future-data leakage
- Documented and testable Python scripts
