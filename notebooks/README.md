# Jupyter Notebooks

This folder contains exploratory analysis and validation
notebooks for the FinCorp Payment Fraud Monitoring &
Risk Analytics System.

## Planned Notebooks

1. Data profiling and quality assessment
2. Transaction and customer behaviour analysis
3. Fraud pattern exploratory analysis
4. Fraud feature investigation
5. Risk score distribution analysis
6. Fraud detection validation and error analysis

## Tools
- Python
- Pandas and NumPy
- Matplotlib and Seaborn

## Standards
- Explain the business question before analysis.
- Use reproducible calculations.
- Document findings using actual results.
- Avoid using future transactions when calculating
  historical risk features.
- Keep final test data separate from rule development
  and tuning.
